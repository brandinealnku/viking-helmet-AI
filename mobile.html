Interactive AI Mirror

This demo shows how a webpage can respond in real time using camera input, face tracking, background replacement, and visual overlays. It is designed to be simple, interactive, and easy to use on desktop or mobile.

How to use it

  1. 1. Select Start Camera & AI to begin.
  2. 2. Choose a mode like Glasses, Helmet, Viking Combo, or Griffin Hall.
  3. 3. Use Capture Snapshot to save an image to your device.

What it demonstrates

• Camera access with getUserMedia
• Real-time face tracking with BlazeFace
• Background compositing with BodyPix
• Canvas-based overlays for interactive web experiences

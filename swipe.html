Hand Gesture Website Navigation

This demo turns a webcam into a gesture controller for a webpage navigation bar. Instead of clicking tabs, a user can move through the menu with a hand swipe and select the current section by holding an open palm steady.

How to use it

  1. 1. Tap Start Camera & AI.
  2. 2. Move one hand clearly into view with your palm facing the camera.
  3. 3. Swipe your hand right to move to the next navigation item.
  4. 4. Swipe your hand left to move to the previous navigation item.
  5. 5. Hold an open palm steady to open the highlighted section.

What it demonstrates

• Camera access with getUserMedia
• Real-time hand landmark detection in the browser
• Motion-based swipe detection using palm position
• Gesture-driven navigation and section switching

About

How the Demo Works

The app detects hand landmarks from the webcam, estimates the palm center, and watches how that center moves over time. A strong horizontal motion is treated as a swipe gesture. A steady open palm becomes a select gesture.

Swipe Detection

Tracks palm center changes across recent frames and looks for a strong left or right motion.

Open Palm Select

Recognizes an open hand and waits briefly before confirming selection.

Nav Highlighting

Each swipe changes the active navigation pill so the user always sees where they are.

Content Switching

When selected, the corresponding page section is revealed instantly.
